# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct. The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and applies to every space this project runs: issues, pull requests, discussions, and any event or channel representing the project.

In short: be respectful, assume good faith, keep disagreement about the work and not the person, and accept that maintainers will act on behaviour that makes the project unwelcoming.

Reports go to conduct@griotdata.com. Reports are handled confidentially by the maintainers, and reporters will receive a response within five working days.
