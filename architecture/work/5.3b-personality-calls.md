# 5.3b: The Linux personality serves the calls pyarrow asks for

- **System design:** `architecture/moruna-os-system.md`, section 5C (Python) and the Linux personality.
- **Needs:** 5.3's probe (merged, 9ec6a7a0). **Rules:** `architecture/work/_rules.md`.

## Why

5.3's probe (`KC1 pyarrow: ok`) imported pyarrow 25.0.1 and pyarrow.compute and added a column, with
1,697 calls served. glibc fell back on each refused call, but each fallback is slower or loses a
guarantee.

| Call | Count | What its refusal costs |
|---|---|---|
| `mremap` (25) | 6 | Every large `realloc` allocates anew, copies and frees. |
| `clone3` (435) | 1 | Each `pthread_create` tries `clone3`, fails, then uses `clone`. |
| `set_robust_list` (273) | 2 | Robust mutexes lose their owner-died recovery. |
| `sysinfo` (99) | 2 | It is refused only for plain `run` programs; it is already served on the data plane. |
| `rseq` (334) | 1 | `sched_getcpu` falls back to the `getcpu` call. |

## Build

1. **`mremap`** on a private anonymous mapping: grow or shrink in place when the addresses after it
   are free, otherwise move it (`MREMAP_MAYMOVE`) by mapping the same memory at a new address, with
   no copy. Charged to the process's account as `mmap` is.
2. **`clone3`:** read `struct clone_args` and accept the same thread flags `clone` accepts, mapped
   onto the existing `clone` path. Anything else is refused with `ENOSYS`, as today.
3. **`set_robust_list`:** keep each thread's list head. When the thread ends, mark the robust futexes
   it held as owner-died (`FUTEX_OWNER_DIED`) and wake their waiters.
4. **`sysinfo`** for plain `run` programs, from the program's account, as the data plane answers it.
5. **`rseq` is not built here.** It needs the scheduler to abort critical sections on preemption.
   Note it as a known limit.

## Success

- Host tests for each call.
- 5.3's probe boots with no refused call except `rseq`, and pyarrow still prints `KC1 pyarrow: ok`.
- CI's boot check still passes.

## Report

The commits, the tests, and the probe's line with its refused calls.
