# 5.3: Python functions on the node

- **System design:** `architecture/moruna-os-system.md`, sections 0 and 5C.
- **Needs:** 3.2. **Rules:** `architecture/work/_rules.md`.

## Build

The cloud profile's Linux layer (`kernel/linux`) runs an `image` function built by
`python/moruna/_build.py` from CPython 3.14 and pyarrow. Fix what stops it in the image builder or
the profile. Changes to `kernel/linux` are asked first.

## Success

A Python function that adds a column gives the expected rows in a booted job. The time to first
rows is recorded.

## Report

The commits, the boot log and the timing.
