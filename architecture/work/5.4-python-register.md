# 5.4: `moruna.register`

- **System design:** `architecture/moruna-os-system.md`, sections 3E and 5C.
- **Needs:** 5.3 and 3.6. **Rules:** `architecture/work/_rules.md`.

## Build

`moruna.register(fn, client, *, store, key)`: build the image, sign its SHA-256 with `key`, upload it
to `store` (an object-store URL the node can reach), and call `POST /v1/functions` through
`moruna.api`.

## Success

From the Mac, against a booted node with fake object storage on the host: a decorated function is
registered and runs in a submitted job.
