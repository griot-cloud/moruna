# 6.2: The first full run

- **System design:** `architecture/moruna-os-system.md`, section 6.
- **Needs:** 3.8 and 6.1 merged. **Rules:** `architecture/work/_rules.md`.

## Goal

The table of 6B for the four NYC taxi jobs on 2024, logged.

## Run

The PM runs `bench/node/run.py --plan nyc-2024` in `griot-dev` (6A). The agent:
1. reads the results in `bench/node/results/<date>/`;
2. writes the table into `architecture/benchmark-log.md`: per job and engine, the median of 5 of
   operational time, start-up, CPU-seconds, peak memory and the hash check;
3. marks every job where Moruna misses the bar (faster than 0.6.6; then 1.5x the best engine on
   operational time, CPU-seconds no worse);
4. for each miss, gives the report's time split (read, decode, function, encode, write, waits)
   and names the stage that lost.

## Success

The table and the list of misses, each with its losing stage. No fixes here: each miss becomes a
6.3 item.

## Report

The table, the misses, and the resource group's deletion.
