# 3.7: Following a job over MCP

- **System design:** `architecture/moruna-os-system.md`, sections 2D and 3B.
- **Needs:** 3.2 and 2.4. **Rules:** `architecture/work/_rules.md`.

## Goal

An agent follows a job from submission to report using MCP alone.

## Build

1. **Tools** for 3B's operations, from the regenerated `mcp-tools.json`.
2. **Events over MCP:** the tool `moruna_job_events` takes `id` and `from` and returns up to 1,000
   records after `from`, with `next` to continue. MCP stays stateless, so an agent polls.

## Success

On a booted node: an MCP client submits a test job, polls its events through to `report` and
`exit`, and reads the report; `from` resumes where it left off.

## Report

The commits and a transcript of the MCP exchange.
