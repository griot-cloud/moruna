# 4.2: `expr`, one fused pass over an expression tree

- **System design:** `architecture/moruna-os-system.md`, sections 4A, 4B (`expr`'s vocabulary),
  4C, 4G.3. **Needs:** 4.1's specification and corpus formats (agent on 4.1; the PM forwards the
  commit). **Rules:** `architecture/work/_rules.md`.

## Build

1. **The specification** (`spec/expr.md`, in 4.1's format). The vocabulary is Arrow compute's
   elementwise functions:
   - arithmetic, wrapping and checked;
   - comparison, and Boolean logic with nulls;
   - `if_else` and `case_when`, `coalesce` and `fill_null`, `cast`;
   - temporal parts (hour, day of week and the like);
   - rounding with the mode named;
   - unary maths.

   The tree has Substrait's shape: literal, column, cast, if-then, switch, function call. State
   every null, overflow and rounding rule.
2. **The JSON form** of a tree, as a job document's kernel argument, and its schema check. It
   replaces `moruna.std.filter`'s expression language. Existing documents that use the old
   language keep working through a translation, with a test.
3. **The CPU reference:** it evaluates the whole tree in one pass over the batch, not one Arrow
   call per node, and allocates only the output columns. How it fuses is the implementer's
   choice: compile, or interpret over chunks that stay in cache. Report which, and why.
4. **The corpus,** including Audit's rule (`bench/vm/workloads.py`). Its four behaviours must be
   reproduced exactly:
   - a null distance counts as zero;
   - a null rate code takes the standard branch;
   - a null fare is never flagged;
   - the flag uses the unrounded fare, while the output is rounded half-to-even at two decimals.

## Measure (4G.3)

On a real month (`~/moruna-data/nyc/norm/yellow_tripdata_2024-01.parquet`), on the Mac, with
interleaved runs and the Mac's load recorded:
- Enrich's columns as one `expr`, against the sixteen separate Arrow compute calls;
- Audit as one `expr`, against its Python loop.

## Success

- Audit and Enrich's derived columns, each as one `expr`, give 0.6.6's rows on a month (the
  canonical check the benchmark uses).
- The measurement, and coverage of 80% or more.

## Report

The spec, the JSON form, how the reference fuses, the corpus, the measurement, coverage and the
commits.
