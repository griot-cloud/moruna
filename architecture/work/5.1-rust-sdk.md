# 5.1: `moruna-function`, the Rust SDK

- **System design:** `architecture/moruna-os-system.md`, section 5A.
- **Needs:** phase 1 none; phase 2 needs 3.2. **Rules:** `architecture/work/_rules.md`.

## Build

1. `kernel/function/rust`, package `moruna-function`, exactly 5A's API: `serve`, `Emit`, `log`,
   `FunctionError`, over `moruna_sys::plane::Rings` and arrow-rs's IPC reader and writer. A batch is
   read in place from its window.
2. A guide, `kernel/function/rust/README.md`: write a function, build it, register it.
3. An example, `kernel/function/rust/examples/double`: doubles an integer column.
4. Move the gate's seven functions (`images/gate/tasks`) onto it. Their logic is unchanged.

## Success

- Phase 1, on the host: the SDK's logic tested over an in-memory stand-in for the rings; every gate
  function's own tests pass after the move.
- Phase 2, booted: each gate function gives the same rows as before, in a job; the example runs in
  a job.

## Report

The commits, the test results, and the boot results.
