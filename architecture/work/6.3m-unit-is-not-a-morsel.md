# 6.3m: on a pipelined stage, a unit's output is not its own morsel's

- **System design:** `architecture/moruna-os-system.md`, section 3A (the engine sizes from what a
  run observes: 6.3b's learned growth, the controller, the cost model). **Rules:**
  `architecture/work/_rules.md`, and 6.3's steps: write the defects as tests, then **stop and
  report** with a proposal before fixing.
- **Found by:** 6.3j (2026-11-18). Its fix A makes a stage's first unit answer its whole morsel,
  which corrects the controller's probe. Every other reader of a single unit is still wrong.

## The defect

A ring stage (a function task, `TaskState::pipelined` in `crates/moruna-micro/src/task.rs`) posts
a morsel's pieces and returns what answers have come. Later answers come with later units, or at
the stage's end. So a unit pairs one morsel's input with other morsels' output.

Measured on 6.3j's host model (`crates/moruna-runtime/tests/ring_stage_probe.rs`, branch
`work/6.3j-probe-first-piece` at 5c697de7): a 160 MiB input, 10 units, a function whose real out/in
is 1.17.

| Reader | What it gets | Truth |
|---|---|---|
| `learn_growth`, the largest out/in of any one unit (it cuts reads through `grown`, `source_drive.rs`) | 1.63 and 1.67 | 1.17 |
| The trace's per-morsel record | 1 unit of 10 gives its own morsel's answer; out/in runs 0.00 to 1.63 | 1.17 each |
| The cost model's per-unit pairs | a fitted line gives 0.97; a unit's bytes out are off by 14–15% at the median, 100% at worst | 1.17 |

The units' bytes out sum to 0.86 of the stage's. The other 14% is given at the stage's end and
belongs to no unit. The stage's totals over the run are right.

## Do

1. **Write each reader's defect as a failing host test** on 6.3j's model: learned growth, the
   trace's per-morsel record, and the cost model's observation each equal the truth for a
   function with a known out/in.
2. **Stop and report a proposal.** The PM's starting point is that an answer belongs to its
   morsel. The stage knows which pieces came from which morsel, so it can report each morsel's
   output when that morsel's last answer arrives, and the readers take completed morsels, not unit
   returns. Say what that changes in the contract between the scheduler and a kernel, what it
   costs, and how it behaves for kernels that are not pipelined. Give alternatives, including
   readers that use stage totals only.

## Refused

A correction factor applied to per-unit figures.

## Report

The tests, the proposal with alternatives, and what each reader would then see.
