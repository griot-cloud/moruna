## What 1.6's runs on Servercore ru-3 found wrong in `kernel/node/OPENSTACK.md`

1. **No machine goes directly on `external-network`** ("Failed to allocate the network(s)"). A run makes a private network and subnet, a router with the external gateway and the subnet added, puts the server on the private network, and gives it a floating IP.
2. **The flavor rule must also cover the image:** the flavor's RAM must be at least the image's `--node-memory`, and the cloud profile's fixed accounts are 832 MiB, so the smallest workable flavor has 2 GiB.
3. **A volume boot needs a zero-disk flavor** ("It is restricted to create volume-backed server with non zero disk flavor").
4. **Volume types are per zone** (`basic.ru-3b`). A volume needs `--type <x>.<zone>` and `--availability-zone <zone>`, and the server the same zone.
5. **Cleanup must bound each call:** `router unset --external-gateway` once hung for 38 minutes. Delete in reverse order: floating IP, server, volume (after it detaches), router subnet, router gateway, router, subnet, network, group, image.
6. **Read the console every few seconds from the create on, keeping its errors.** A node that stops goes SHUTOFF within about 30 s.
