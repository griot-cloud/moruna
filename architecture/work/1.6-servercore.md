# 1.6: Bring-up on Servercore

- **System design:** `architecture/moruna-os-system.md`, section 1E.
- **Needs:** 1.4 and 1.5 merged, and the PM's go-ahead in your brief. **Rules:**
  `architecture/work/_rules.md`, except that this item creates resources on Servercore, in project
  `moruna`, with cloud `servercore` (`~/.config/openstack/clouds.yaml`).

## Goal

A machine created from our image on Servercore comes up with nobody logging in.

## Build

1. Follow `kernel/node/OPENSTACK.md` (1.5) exactly. Where it's wrong, fix the recipe in the same
   commit.
2. Node config: one test token key, made for this run; the private half stays on this Mac, under
   the item's own output folder, and is never committed.
3. Record: create-to-ready time, from `server create` returning to the `ready` line in the console
   log; and `boot_ms`.
4. Delete everything you created, then list the project's servers, images, volumes, ports, floating
   IPs and security groups to show nothing of yours is left.

## Success

- The console log shows every boot line through `ready`.
- From this Mac, port 443 of the machine's public address accepts a connection, and any other port
  is refused.
- Everything created is deleted.

## Limits

- One machine, the smallest flavor of 1 CPU and 1 GiB or more, for at most one hour.
- If the image is refused, or `hw_machine_type` is ignored (1E), stop and report.

## Report

The commands run, the console log, both times, and the clean-up listing.
