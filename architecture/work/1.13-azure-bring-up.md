## Build

`kernel/node/AZURE.md`: every command, as `OPENSTACK.md` does for Servercore: upload the VHD, make
a Generation 2 image, create one `Standard_D2s_v4` in zone 3 with security type `Standard`,
accelerated networking off, node config as user-data, an inbound rule for 443 only, read the
console, delete everything. Then run it.

## Success

1E's success, on Azure: the machine reaches `ready` with nobody logging in, port 443 accepts and
other ports refuse, `GET /v1/node` answers over HTTPS from the Mac, and everything created is
deleted. Record create-to-ready and `boot_ms`.
