# 1.3c: The node stops answering on the network during a copy

- **System design:** `architecture/moruna-os-system.md`, sections 1B, 1C and 2B.
- **Needs:** nothing new. **Rules:** `architecture/work/_rules.md`.

## The miss

Found by 3.5's lock turn (2026-11-18), run 1. A cloud node was under QEMU TCG with 2 CPUs, an S3
copy job (MinIO in `moruna-arm`) and then Blob on the same boot:

- About 3 s into the S3 copy, the node stopped acknowledging. The capture shows it stopped after
  about 86 KB from MinIO.
- It never answered later connections to its API on 443.
- The console printed nothing for more than 2 minutes.
- Three later boots of the same image ran their copies to the end.
- The evidence (`net.pcap`, `net-tcp.txt`, `console.log`) is in
  `.claude/worktrees/agent-a506afa8a73c83859/.boot-a506afa/results-run1/`, with the run script
  beside it.

**The rule this breaks:** one job's connection never stops the node's network or its API. The API
answers while a job runs, whatever the job does (2B).

## Do

1. **Read the evidence.** From the capture, say which side stopped first and what was in flight:
   windows, retransmissions, the last segments each way.
2. **Reproduce it** under QEMU in one lock turn, with the same copy run repeatedly. Use 3.5's run
   script and its MinIO and Azurite, which are kept in moruna-arm at
   `/root/target/a506afa8a73c83859`. Run with a console line each second from the network server
   and from the core (a heartbeat in a debug image only), so that a hang shows which process
   stopped: the driver's receive path, the network server, a lock in the core, or the engine
   holding something the network server waits on.
3. **Name the cause** in the code: the file, the function, and why.
4. **Fix it at the cause,** with a test that shows it without the copy: a host test where it can be
   one, otherwise a booted check. A timeout that hides it is not a fix.

## Report

The reading of the capture, the reproduction (how many runs, how many hangs), the cause, the fix and
its test, and a run of 10 copies in a row with no hang.
